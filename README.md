# Intelligent-CPU-Scheduler-Simulator

Welcome to the **Intelligent CPU Scheduler Simulator**! This project is designed to simulate and visualize how different CPU scheduling algorithms work behind the scenes in an operating system.

##  Features
- Visualizes popular CPU scheduling algorithms (e.g., FCFS, SJF, Round Robin, Priority Scheduling).
- Calculates important metrics like Turnaround Time, Waiting Time, and Average Times.
- Simple and easy-to-understand simulation output.

##  How to Run
1. Clone or download this repository to your local machine.
2. Open the project in your preferred terminal or IDE.
3. Compile and run the main application file.
4. Input your processes, arrival times, and burst times to see the simulation in action!
